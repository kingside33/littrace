# [AGENTS] AGENTS.md 不硬编码 node 测试文件清单,改为引用 ci.yml 两处显式清单

- 日期:2026-11-18
- 状态:已接受

## 背景

`CONTRIBUTING.md` 既有约定:不要在文档里硬编码测试清单 —— 清单会漂移,文档不会有人
跟着改。但 `AGENTS.md` 的「验证入口」节又必须与 `ci.yml` 的真实命令对齐,否则会话照抄
文档跑出来的东西与 CI 不是一回事。两者在这一个点上直接冲突。

## 决策

验证入口写成 `node --test <ci.yml 显式清单>`,并在正文说明新增 `tests/test_*.cjs` 时要
同步 `ci.yml` 的两处(守卫清单与运行清单),文档里不复述具体文件名。数量以
`git ls-files "tests/test_*.cjs"` 为准,不写进本文。

## 备选

- **备选 A:直接在文档里列全全部测试文件**。更直观,照抄即可跑。不选:文件一增删文档
  必然漂移,而且违反 `CONTRIBUTING.md` 已经写明的约定;一处约定被文档自己破掉,后续
  就没有理由要求别人遵守。

## 后果

文档不会随测试文件增删而失效。代价是读者要看具体清单得再打开 `ci.yml`;漏登记的风险
由 `ci.yml` 的守卫步骤挡住 —— 它会把「已被 git 跟踪但不在清单里」的文件列出来并失败,
这正是裸 `node --test` 目录 glob 会掩盖的失效模式。
