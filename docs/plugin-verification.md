# 真机验收结论(M0 + M1)

状态:AI 代跑验收记录(维护者未复核)｜日期:2026-11-19｜环境:Zotero 10.0.8 (x64 en-US) / Windows 10.0.26200 / littrace 服务 0.1.0 / 插件 0.1.0(占位 pluginID `littrace@example.invalid`)

本文件是 M0 十项验收与 M1 UI 清单的可追溯记录。**每一项的判定都依赖截图或日志证据**;无法在本机自动化构造的场景如实标"受阻",不以推测代替结论。

- 验收方式:隔离 Zotero profile(不触碰维护者现有 profile 与其 9 个插件)+ 真实库只读快照(412 篇文献、49 个合集、Zotero schema 10.0.8)+ 独立数据目录的服务进程。
- 证据目录:截图在 `.tmp-verification/shots/`,Zotero debug log 在 `.tmp-verification/zotero8.log`(该目录被 `/.tmp-*` 规则忽略,不入库)。
- 发现 3 个真实缺陷(#56/#57/#59),修复见 PR #58,复验通过后才记 pass。

## go/no-go

**决定:条件 go(维护者,2026-11-19)。**

判定依据:闸门口径是「⑦⑧⑨ 任一彻底不可行且无退路 → 停止或重定义」。截至本文件:

| 关键项 | 状态 | 对闸门的意义 |
|---|---|---|
| ⑦ tab 打开机制 | **已定案**(`Zotero_Tabs.add` 主路径可用) | 最不确定的机制假设已消除 |
| ① iframe 渲染 + hash 直达 | **已通过** | 页面承载能力已证实 |
| ⑧ 谱系「谱系」列 | 未验 | 未验 ≠ 不可行;列注册 API 是官方文档明确记载的 |
| ⑨ 阅读器问答面板 | 未验 | 同上;但承载机制有已定案的三条退路 |

**条件(硬门槛,不满足不得发布 beta)**:

1. 补验 ⑧「谱系」列(排序/导出/徽标点击)与 ⑨ 阅读器面板承载机制,并把结论回填本文件;
2. 补验 ④ 深链跳页(需库内存在关系数据,或用阅读器划词链路替代验证);
3. 三项任一失败时,按设计文档的退路处理(列降级为条目面板 section;阅读器降级为条目面板;深链降级为复制链接),退路本身也要有验证记录。

**保持 unverified 的部分**:`docs/support-matrix.json` 的 `plugin` 节在 ⑧⑨④ 与 M1 手动清单全部通过前不提升状态 —— 条件 go 是针对开发推进的,不是对用户的兼容性承诺。
