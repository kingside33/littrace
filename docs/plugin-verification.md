# 真机验收结论(M0 + M1)

状态:AI 代跑验收记录(维护者未复核)｜日期:2026-11-19｜环境:Zotero 10.0.8 (x64 en-US) / Windows 10.0.26200 / littrace 服务 0.1.0 / 插件 0.1.0(占位 pluginID `littrace@example.invalid`)

本文件是 M0 十项验收与 M1 UI 清单的可追溯记录。**每一项的判定都依赖截图或日志证据**;无法在本机自动化构造的场景如实标"受阻",不以推测代替结论。

- 验收方式:隔离 Zotero profile(不触碰维护者现有 profile 与其 9 个插件)+ 真实库只读快照(412 篇文献、49 个合集、Zotero schema 10.0.8)+ 独立数据目录的服务进程。
- 证据目录:截图在 `.tmp-verification/shots/`,Zotero debug log 在 `.tmp-verification/zotero8.log`(该目录被 `/.tmp-*` 规则忽略,不入库)。
- 发现 3 个真实缺陷(#56/#57/#59),修复见 PR #58,复验通过后才记 pass。

## M0 验收项

| 项 | 结论 | 证据 | 备注 |
|---|---|---|---|
| ① 服务页面在 Zotero tab iframe 渲染 + hash 直达 | **通过** | `03-graph-tab-ok.png`:tab 内完整渲染「文献演化谱系」页面(侧栏导航、研究链/时间演化/引用网络三视图、412 篇计数、14 个方法大类、关系核验区块);a11y 树含页面全部文本节点;URL 为 `http://127.0.0.1:8765/#graph` | 初版实现空白,见 #56/#57/#59 与 PR #58 |
| ② GET /api/session + 带 token POST 全链路 | **通过** | debug log 显示插件发起 `GET /api/v2/paper?paper=z:1:...` 等带 token 的请求并成功;页面「本地知识库已连接」;412 篇文献与 14 个方法大类由服务端数据渲染 | 非 GET 请求均经 S4 客户端统一封装 |
| ③ 特权 XHR 的 Origin 行为 + 特权宿主访问跨源 DOM | **部分通过** | 通过项:特权 XHR 未被 `service.py` 的 Origin 校验拒绝,全部 200;整个验收过程 `Error: littrace` 计数为 **0**。未通过项:深链桥接的跨源 DOM 注入未单独验证(见 ④) | 结论只覆盖"特权 XHR 可用";跨源 DOM 访问另见 ④ |
| ④ zotero:// 深链桥接 | **受阻** | 两条触发路径都不可用:① 图谱页关系数为 0,无命中徽标可点;② 阅读器侧栏问答卡片需要先打开 PDF,而 ⑨ 的窗口/附件问题同样阻塞 | 需真实关系数据,或 ⑨ 可验后在阅读器内点引用徽标 |
| ⑤ 双客户端并发写 | **受阻** | 未构造:插件侧当前无"提交任务"入口(调度台是 iframe 内的服务页面,提交动作属于服务端单一写路径),无并发写的可观测面 | 建议在 M1 联调时用 Web UI + iframe 内调度台同时提交验证 |
| ⑥ schema migration 运行中插件面板行为 | **受阻** | 未构造:隔离数据目录是全新索引,不存在 migration 场景;强行构造会污染验收环境 | 需专门的 migration 夹具 |
| ⑦ tab 打开机制定案 | **通过(主路径)** | 修 PR #58 后,`Zotero_Tabs.add` 主路径生效:tab 栏出现「研究谱系」tab,窗口标题变为「研究谱系 - Zotero」,内容区渲染出页面;debug log 零 Error | **定案:`Zotero_Tabs.add` 主路径可用**(需 `data` 选项与 `{id, container}` 返回值契约);`window.openDialog` 退路保留但不作为首选 |
| ⑧ 条目列表「谱系」列真机 | **通过(核心)** | 第二轮补验:列选择器中同时出现「谱系」与「精读」两项;开启后表头出现「谱系」列;点击列头排序无错误;列数据经 914 次 `/api/v2/paper` 请求真实拉取(200 为主,404 项按空态处理不抛错);全程 `Error: littrace` = 0 | 视觉层徽标与 CSV 导出未截图为证(本轮窗口截图不可用),留维护者一眼确认 |
| ⑨ 阅读器问答面板承载机制 | **受阻(环境)** | 已实现且单测覆盖,但本轮无法在 GUI 打开 PDF:隔离 profile 的窗口在本会话中无法前台化(Windows 拒绝 `SetForegroundWindow`),双击/键盘路径均不可用;a11y `AXExpand` 不暴露附件子行。另:快照库 345 个 PDF 附件中仅 278 个文件真实存在 | 需维护者手动打开一个 PDF(或让窗口保持可聚焦)后再验 |
| ⑩ 版本协商端点行为 | **通过** | `curl /api/version` → `{"service_version":"0.1.0","api_version":"v2"}`;插件状态点显示「littrace 服务:在线」;诊断弹层显示「服务版本 0.1.0 / 插件最低要求 0.1.0 / 兼容性:在支持范围内」(`04-diagnostics.png`) | 三处口径一致 |

## 本轮发现并修复的缺陷

| issue | 缺陷 | 修复 | 复验 |
|---|---|---|---|
| #56 | `Zotero_Tabs.add` 返回值被当作字符串,实际是 `{id, container}`;`data` 选项缺失导致 `tab.data === undefined` | PR #58 | 通过:tab 正常出现、标题正确、零 Error |
